کلین آی‌پی اسکنر چیست؟What is Clean IP Scanner?

        

          یک ابزار وب کاملاً محلی برای پیدا کردن IPهای «پاک» — یعنی IPهایی که سریع‌اند، پاسخ می‌دهند و برای عبور از فیلترینگ یا اتصال به سرویس‌های CDN مناسب‌اند. همه‌چیز روی سیستم خودت اجرا می‌شود: دیتابیس لوکال است، اسکن لوکال است و هیچ داده‌ای جایی ارسال نمی‌شود.
          A fully local web tool for finding clean IPs — fast, responsive addresses that work well with CDNs and circumvention setups. Everything runs on your machine: the database, the scans, the scheduler. Nothing ever leaves your box.
        

        

          رابط کاربری دوزبانه است (انگلیسی پیش‌فرض و فارسی راست‌به‌چپ با یک کلیک) و موتور اسکن یک سرویس مستقل Bun است که با socket.io به رابط وصل می‌شود — به همین دلیل پیشرفت اسکن در لحظه و بدون رفرش دیده می‌شود.
          The UI is bilingual (English by default, full RTL Persian one click away), and the scan engine is a standalone Bun service connected via socket.io — that is why scan progress streams live, without refresh.
        

        

          💡 نکته💡 Tip
          «IP پاک» یعنی کمتر گزارش‌شده و کمتر بلاک‌شده — ابزار با تأخیر و سرعت دانلود واقعی آن را رتبه‌بندی می‌کند.
          A “clean” IP is one that is less flagged and less blocked — the tool ranks candidates by real latency and download speed.

        فصل دومChapter 2
        
نصب و راه‌اندازی در ۴ قدمSetup in four steps

        

          پیش‌نیاز فقط Bun نسخه ۱.۱ به بالاست. مخزن را کلون کنید و چهار دستور زیر را اجرا کنید:
          The only prerequisite is Bun 1.1+. Clone the repo and run the four commands below:
        

        

          
1 · clone & install

          
git clone https://github.com/CheginiSoroush/clean-ip-scanner.git
cd clean-ip-scanner
bun install

        

        

          
2 · database (SQLite + Prisma)

          
bun run db:push

        

        

          
3 · web app → :3000

          
bun run dev

        

        

          
4 · scan engine → :3003

          
cd mini-services/scan-service
./run.sh

        

        

          ⚠️ مهم⚠️ Important
          موتور اسکن باید روشن بماند؛ اگر خاموش شود رابط کاربری حالت «قطع» را نشان می‌دهد و اسکن شروع نمی‌شود.
          Keep the engine running; if it is down the UI shows a “disconnected” state and scans will not start.

        فصل چهارمChapter 4
        
شکارچی گوگل و زمان‌بان شکارGoogle hunter & hunt scheduler

        

          شکارچی IP گوگل رنج‌های رو‌به‌گوگل را از منابع زنده جمع می‌کند: رکوردهای SPF، رنج‌های API، اسنپ‌شات‌های RIPE و… . سلامت هر منبع گزارش می‌شود و نتایج در «دانش‌نامه» ذخیره می‌ماند تا اسکن‌های بعدی سریع‌تر شوند.
          The Google IP hunter collects Google-facing ranges from live sources: SPF records, API ranges, RIPE snapshots and more. Source health is reported and results persist in a knowledge base, making later hunts faster.
        

        

          زمان‌بان شکار اجازه می‌دهد شکار به‌صورت دوره‌ای و سمت سرور اجرا شود. هر اجرا در «ژورنال» ثبت می‌شود و یک بازتاب تنظیمات فشرده (پروایدور، هدف، دسته، همزمانی، host:port، سرعت، سطح تأیید) کنار نتیجه می‌ماند — حتی بعد از ری‌استارت.
          The hunt scheduler runs hunts periodically on the server side. Every fire is recorded in the journal with a compact settings echo (provider, target, batch, concurrency, host:port, speed, verify) — persisted across restarts.
        

        

          💡 ترفند💡 Pro tip
          ژورنال اجراها را می‌توانید با یک کلیک به CSV ببرید و در اکسل تحلیل کنید.
          Export the run journal to CSV with one click and analyze it in your spreadsheet.

        فصل پنجمChapter 5
        
اسکنر WARPWARP scanner

        

          در تب WARP می‌توانید اندپوینت‌های کلادفلر WARP را پروب کنید: نرخ زنده‌بودن، تأخیر و تاریخچه هر دسته پروب ذخیره می‌شود تا روند سلامت شبکه‌تان را ببینید.
          The WARP tab probes Cloudflare WARP endpoints: alive-rate, latency and full history per probe batch are stored so you can watch your network’s trend.
        

        
        

          ⚠️ محیطی⚠️ Environmental
          اگر شبکه‌تان UDP را بسته باشد، نرخ زنده‌بودن صفر نشان داده می‌شود — این محدودیت شبکه است، نه باگ ابزار.
          If your network blocks UDP, the alive-rate will read zero — that is a network restriction, not a bug.

        فصل ششمChapter 6
        
تلگرام و DDNS کلادفلرTelegram & Cloudflare DDNS

        

          در تب یکپارچه‌سازی، توکن ربات و شناسه چت را وارد کنید تا خلاصه نتایج به تلگرام‌تان برسد — دستی یا خودکار پس از پایان هر اسکن. اجراهای زمان‌بندی‌شده به‌طور خودکار CSV ژورنال را هم پیوست می‌کنند.
          In the Integrations tab, enter your bot token and chat ID to receive result digests — manually or automatically after each scan. Scheduled runs auto-attach the journal CSV via sendDocument.
        

        

          DDNS کلادفلر هم بهترین IP پاک را مستقیم روی رکورد A دامنه‌تان می‌گذارد؛ دستی یا خودکار با آستانه حداقل IP.
          Cloudflare DDNS pushes the best clean IP straight to your domain’s A record — manually, or automatically with a minimum-IP threshold.

Troubleshooting

        

          

            
SymptomFix

            
              
UI shows “disconnected”Start the engine: cd mini-services/scan-service && ./run.sh

              
Scan returns nothingLower concurrency, raise timeout, try another port (443 → 2053/2083/2087)

سؤالات پرتکرار
Frequently asked

        
آیا داده‌هایم به سروری ارسال می‌شود؟Is my data sent anywhere?
نه. اسکن، دیتابیس و زمان‌بان همگی لوکال‌اند؛ فقط اگر خودتان تلگرام را پیکربندی کنید گزارش‌ها به ربات خودتان می‌روند.No. Scans, the database and the scheduler are all local; only if you configure Telegram yourself do digests go to your own bot.

        
تفاوت «اسکن» و «شکار» چیست؟Scan vs hunt — what is the difference?
اسکن، رنج‌های یک پریست CDN را بررسی می‌کند؛ شکار، رنج‌های رو‌به‌گوگل را از منابع زنده می‌یابد و برای همان‌ها اسکن می‌چیند.A scan probes a CDN preset’s ranges; a hunt discovers Google-facing ranges from live sources and builds scans on top of them.

        
روی ویندوز / مک کار می‌کند؟Does it run on Windows / macOS?
بله — هر دو بخش روی Bun اجرا می‌شوند که برای هر سه سیستم‌عامل نسخه دارد.Yes — both parts run on Bun, which ships for all three platforms.

        
چطور از همه‌چیز پشتیبان بگیرم؟How do I back everything up?
فایل db/custom.db را کپی کنید — کل تاریخچه، تنظیمات و ژورنال همان‌جاست.Copy db/custom.db — all history, settings and the journal live there.

        
لایسنس چیست؟What is the license?
MIT — آزاد برای استفاده شخصی و تجاری با ذکر نام نویسنده.MIT — free for personal and commercial use with attribution.
